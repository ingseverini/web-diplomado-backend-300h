# Proyecto Backend: web-diplomado-backend-300h

Este es el backend del proyecto final del diplomado. Está construido con Node.js, Express.js y MongoDB.

## Tecnologías utilizadas

- Node.js
- Express.js
- MongoDB
- Mongoose
- Dotenv
- CORS

## Cómo ejecutar el servidor

1. Clonar el repositorio.
2. Instalar dependencias con: `npm install`
3. Crear un archivo `.env` con las variables necesarias.
4. Ejecutar el servidor con: `node app.js` o `nodemon app.js` si tienes nodemon.
